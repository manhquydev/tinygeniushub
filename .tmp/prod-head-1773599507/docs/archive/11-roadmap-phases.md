# 11 — Roadmap theo giai đoạn (Deliverables)

> Bạn nói rõ: chưa build vội, cần làm rõ hệ thống + kế hoạch cụ thể.  
Roadmap này ưu tiên **“rõ trước – build sau”**.

## Phase 0 — Alignment (tài liệu hoá & chốt quyết định)
Deliverables:
- Chốt 3 track, cấu trúc level/unit/lesson (file 03 + 05)
- Chốt lesson blueprint + report blueprint (file 04)
- Chốt **plan & limit hồ sơ**: Standard (3) / Family+ (5) (file 07 + 06 + 05)
- Chốt **portfolio retention**: default 90 ngày, opt-in tối đa 365 ngày (file 06 + 05 + 10)
- Chốt **Weekly Report delivery**: in-app + email, có opt-in per child (file 06 + 05 + 10)
- Chốt pricing/funnel/affiliate rules (file 07 + 08)
- Chốt event taxonomy + success metrics (file 09)
- Chốt IA + flows (file 06)
- Chốt “non-functional”: performance, security baseline, observability (file 10)

## Phase 1 — Content system build (nhập liệu & QA)
Deliverables:
- CMS schema chạy được (level/unit/lesson/activity/offline card)
- Bộ template nội dung (file 04) được “đóng khung” thành form nhập liệu
- QA checklist cho 1 lesson (link/video, checkpoint, quiz, offline card, evidence)
- Tối thiểu 20 lesson hoàn chỉnh + 2 weekly report mẫu

## Phase 2 — Core platform build (website-first)
Deliverables:
- Parent account + Child profiles (limit 3, upgrade Family+ limit 5)
- Kid mode + Today’s Mission
- Evidence: checklist + quiz (bắt buộc), photo/audio (opt-in) + portfolio view
- Weekly Report in-app (Reports page + dashboard card)
- Email pipeline: gửi weekly digest + deep link vào dashboard
- Retention job: auto-delete media theo expires_at
- Payment: trial → yearly + upgrade Standard → Family+

## Phase 3 — Growth & optimization
Deliverables:
- Affiliate dashboard + payout rules
- Automation emails (trial day 6/7 report preview, weekly)
- A/B tests theo file 09 (trial length, report format, paywall message)
- Nâng chất “trust stack”: landing proof, case studies, onboarding scripts
