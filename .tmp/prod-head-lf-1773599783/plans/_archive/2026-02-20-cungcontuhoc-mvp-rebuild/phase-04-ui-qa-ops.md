# Phase 04 - UI, QA, Ops

## Objective
Deliver visible MVP flows with guardrails and quality checks.

## Deliverables
- Public pages: home and pricing (Vietnamese UX copy).
- Parent pages: dashboard, children, reports.
- Kid mode page: today's mission and completion path.
- Test suite for locked business rules.
- README and environment setup docs for self-managed deployment.

## Acceptance Criteria
- Core routes are navigable and functional.
- `pnpm lint`, `pnpm type-check`, and `pnpm test` pass.
- Documentation describes next steps for production hardening.
