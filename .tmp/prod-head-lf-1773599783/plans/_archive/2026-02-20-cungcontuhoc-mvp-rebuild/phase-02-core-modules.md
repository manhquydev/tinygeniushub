# Phase 02 - Core Modules

## Objective
Implement identity, child profile management, and content hierarchy primitives.

## Deliverables
- Parent signup/login/logout APIs with secure session cookie.
- Child profile CRUD API with plan-based profile cap enforcement.
- Content schema and seed data for tracks, levels, units, lessons.

## Acceptance Criteria
- Creating child profile blocks once plan limit is reached.
- Content hierarchy can be queried and rendered in UI.
