## Executive Summary

Báo cáo này đánh giá 6 ý tưởng công cụ miễn phí cho chiến lược Engineering as Marketing của nền tảng học tập Abeka tại Việt Nam. Dựa trên nghiên cứu thị trường, phân tích nhu cầu tìm kiếm, và đánh giá khả thi kỹ thuật, chúng tôi đề xuất **3 công cụ ưu tiên**:

| Ưu tiên | Công cụ | Mục tiêu chính | Thời gian xây dựng |
|---------|---------|---------------|-------------------|
| #1 | Đánh giá trình độ tiếng Anh (Cambridge YLE) | Lead generation, SEO | 3-4 tuần |
| #2 | Máy tính chi phí học tập | Conversion, viral | 2-3 tuần |
| #3 | Generator worksheet tiếng Anh/Toán | SEO, repeat visits | 4-5 tuần |

**Dự báo tác động:** 5,000+ leads/tháng trong 6 tháng đầu, 40-60% là đối tượng K4-12 phù hợp với sản phẩm Abeka.

| Học sinh tiểu học | ~8.5 triệu | Bộ GD&ĐT 2024 |

### Insight Chính

1. **Nhu cầu Cambridge YLE rất cao:** Các công cụ như Flyer.vn, Luyện thi Cambridge Online thu hút hàng ngàn người dùng/tháng với bài test miễn phí
2. **Chi phí là pain point lớn:** So sánh chi phí học truyền thống (trung tâm 3-5 triệu/tháng) vs online (500k-1.5 triệu/tháng) là chủ đề được quan tâm

## Đánh Giá 6 Ý Tưởng Công Cụ

### 1. Máy Tính Chi Phí Học Tập

**Mô tả:** So sánh chi phí học truyền thống (trung tâm, gia sư) vs học online với Abeka

| Tiêu chí | Điểm | Phân tích |
|----------|------|-----------|
| Nhu cầu tìm kiếm (VN) | ⭐⭐⭐⭐⭐ | "chi phí học tiếng Anh", "học online tiết kiệm" - high volume |
| Khả thi kỹ thuật | ⭐⭐⭐⭐⭐ | Next.js form + Prisma lưu kết quả - đơn giản |
| Khả năng convert | ⭐⭐⭐⭐⭐ | Kết quả cá nhân hóa → CTA "Tiết kiệm 50% với Abeka" |
| Tiềm năng viral | ⭐⭐⭐⭐ | Share kết quả "Tôi tiết kiệm 15 triệu/năm" |
| Độc đáo vs đối thủ | ⭐⭐⭐ | Có nhiều calculator generic, cần angle Abeka-specific |
| **Tổng** | **24/30** | **RẤT TỐT** |

**Chi tiết nghiên cứu:**
- Phụ huynh VN thường so sánh chi phí trung tâm (Apollo, ILA: 3-5 triệu/tháng) với học online
- Pain point: Chi phí gia sư 1-1 cao (200-400k/giờ) + đi lại mệt mỏi
- Angle viral: "Máy tính tiết kiệm học phí cho con" - emotional trigger mạnh

### 2. Đánh Giá Trình Độ Tiếng Anh (Cambridge YLE)

**Mô tả:** Bài test 20-30 phút đánh giá trình độ Starters/Movers/Flyers theo chuẩn Cambridge

| Tiêu chí | Điểm | Phân tích |
|----------|------|-----------|
| Nhu cầu tìm kiếm (VN) | ⭐⭐⭐⭐⭐ | "test tiếng Anh đầu vào", "kiểm tra trình độ trẻ em" - rất cao |
| Khả thi kỹ thuật | ⭐⭐⭐⭐ | Next.js quiz + Prisma lưu kết quả + email report - medium complexity |
| Khả năng convert | ⭐⭐⭐⭐⭐ | Test xong → "Học tiếng Anh chuẩn Mỹ với Abeka" - natural fit |
| Tiềm năng viral | ⭐⭐⭐⭐⭐ | Phụ huynh share "Con tôi đạt Movers level" trên Facebook |
| Độc đáo vs đối thủ | ⭐⭐⭐⭐ | Flyer.vn, Alokiddy đã có - cần UX tốt hơn + branding Abeka |
| **Tổng** | **28/30** | **XUẤT SẮC** |

**Chi tiết nghiên cứu:**
- Flyer.vn có bài kiểm tra 30 câu với 15,118 lượt xem bài blog
- Alokiddy có test đầu vào được đánh giá cao
- Thị trường Cambridge YLE ở VN rất hot: Starters (Pre-A1), Movers (A1), Flyers (A2)
- Phụ huynh thường không biết con ở level nào để chọn khóa học phù hợp
- **Gap:** Chưa có công cụ kết hợp đánh giá + đề xuất lộ trình học cụ thể với Abeka

## 3 Công Cụ Ưu Tiên

### Công Cụ #1: Đánh Giá Trình Độ Tiếng Anh Cambridge YLE

**Tại sao ưu tiên #1:**
- Highest total score (28/30)
- Natural bridge từ free tool → paid product (Abeka)
- Có sẵn thư viện câu hỏi Cambridge-style
- Flyer.vn đã validate demand với 15K+ views

**MVP Scope:**
```
✓ 30 câu hỏi trắc nghiệm (Listening, Reading, Grammar)
✓ Phân loại: Starters (0-10 điểm), Movers (11-20), Flyers (21-30)
✓ Kết quả: Level + đề xuất lộ trình học Abeka phù hợp
✓ Email capture trước khi xem kết quả chi tiết
✓ Share buttons: Facebook, Zalo
```

**Lead Capture Strategy:**
- **Partial gating:** Show level, gate detailed breakdown + learning path
- **Email required:** Để nhận "Lộ trình học tiếng Anh cá nhân hóa cho bé"
- **Follow-up sequence:**
  - Email 1 (immediate): Kết quả + lộ trình đề xuất
  - Email 2 (day 3): "Tại sao phụ huynh chọn Abeka cho level X"
  - Email 3 (day 7): Testimonial + offer trial

**SEO Strategy:**
- Target keywords: "test tiếng Anh đầu vào", "kiểm tra trình độ trẻ em", "bài test Cambridge Starters"
- Supporting content: "Cambridge YLE là gì?", "Starters vs Movers vs Flyers"

**KPI Targets:**
- Month 1: 1,000 tests completed, 600 emails captured
- Month 3: 5,000 tests/month, 3,000 emails
- Month 6: 10,000 tests/month, 6,000 emails
- Conversion to trial: 15-20%

### Công Cụ #2: Máy Tính Chi Phí Học Tập

**Tại sao ưu tiên #2:**
- Emotional trigger mạnh (tiết kiệm tiền)
- Dễ xây dựng (2-3 tuần)
- Viral potential với kết quả share-worthy
- Có thể A/B test nhiều angle

**MVP Scope:**
```
✓ Input: Lớp học, số giờ/tuần, loại hình (trung tâm/gia sư/online)
✓ Calculation: 
   - Chi phí truyền thống: 3-5 triệu/tháng (trung tâm), 200-400k/giờ (gia sư)
   - Chi phí Abeka: Fixed subscription model
✓ Output: Tiết kiệm/năm + thời gian đi lại tiết kiệm được
✓ CTA: "Bắt đầu tiết kiệm ngay" → Landing page Abeka
```

**Viral Hooks:**
- Shareable result card: "Tôi có thể tiết kiệm 45 triệu/năm cho con"
- Comparison feature: "So sánh với hàng xóm" (nhập zip code)
- Regional insights: "Phụ huynh Hà Nội tiết kiệm trung bình X triệu"

**Lead Capture Strategy:**
- **Ungated:** Tool free to use
- **Soft capture:** "Nhận báo cáo chi tiết qua email" (optional)
- **Retargeting:** Pixel tracking để chạy ads người dùng đã tính

**SEO Strategy:**
- Target: "chi phí học tiếng Anh", "học tiếng Anh bao nhiêu tiền", "so sánh học online"
- Landing page: "Học tiếng Anh chuẩn Mỹ tiết kiệm 50%"

**KPI Targets:**
- Month 1: 2,000 calculations, 500 shares
- Month 3: 8,000 calculations/month
- Month 6: 15,000 calculations/month
- Traffic to Abeka LP: 30% of users

### Công Cụ #3: Worksheet Generator

**Tại sao ưu tiên #3:**
- SEO value cao (worksheet rất được tìm kiếm)
- Repeat usage (phụ huynh quay lại mỗi tuần)
- Link building potential (bloggers, teachers reference)
- Có thể mở rộng thành library lớn

**MVP Scope:**
```
✓ 3 subjects: Tiếng Anh (từ vựng, ngữ pháp), Toán (số học, hình học)
✓ Grade levels: K4, K5, Grade 1-6
✓ Topics: 20+ topics mỗi môn
✓ Output: PDF download (watermarked "Abeka.vn")
✓ Limit: 3 worksheets/month free, unlimited cho members
```

**Content Strategy:**
- **Batch generation:** Upload 100+ worksheets sẵn trước launch
- **Seasonal:** Worksheets theo chủ đề (Tết, Trung thu, Giáng sinh)
- **Trending:** "Worksheet tiếng Anh chủ đề [phim/trend hiện tại]"

**Lead Capture Strategy:**
- **Freemium:** 3 miễn phí, sau đó yêu cầu email
- **Upsell:** "Có 1000+ worksheet trong Abeka Premium"
- **Newsletter:** "Worksheet mới mỗi tuần" drip

**SEO Strategy:**
- Programmatic SEO: `/worksheets/{subject}/{grade}/{topic}`
- Target: "bài tập tiếng Anh lớp 3", "worksheet toán tiểu học"
- Link building outreach đến blog phụ huynh, teacher communities

**KPI Targets:**
- Month 1: 500 downloads, 200 emails
- Month 3: 3,000 downloads/month
- Month 6: 8,000 downloads/month
- Repeat visitors: 40%

## Kỹ Thuật Triển Khai

### Tech Stack (Next.js + Prisma)

```
Frontend:
- Next.js 14 (App Router)
- Tailwind CSS + shadcn/ui
- React Hook Form + Zod validation

Backend:
- Next.js API Routes
- Prisma ORM
- PostgreSQL (Neon/Supabase)
- Redis (caching quiz sessions)

Integrations:
- Resend/SendGrid (email)
- PDF-lib (worksheet generation)
- Google Analytics + Meta Pixel

Hosting:
- Vercel (frontend)
- Neon/Supabase (database)
```

### Database Schema (Simplified)

```prisma
model QuizSession {
  id        String   @id @default(uuid())
  email     String?
  answers   Json
  score     Int
  level     String   // Starters, Movers, Flyers
  createdAt DateTime @default(now())
}

model Worksheet {
  id       String @id @default(uuid())
  subject  String
  grade    Int
  topic    String
  content  Json   // Template data
  pdfUrl   String
}

model Lead {
  id          String   @id @default(uuid())
  email       String
  source      String   // "quiz", "worksheet", "calculator"
  childAge    Int?
  createdAt   DateTime @default(now())
  convertedAt DateTime?
}
```
