## Key Insights
- Use `npx shadcn@canary init` — avoids CLI validation failure on Tailwind v4 CSS-first config
- Keep minimal `tailwind.config.js` for shadcn CLI compat (not used by Tailwind v4 runtime)
- Tailwind v4 uses `tw-animate-css` instead of `tailwindcss-animate`
- Color format: OKLCH preferred for v4, but HSL acceptable for shadcn defaults
- No `src/components/ui/` directory exists yet — shadcn init will create it

## Requirements
### Functional
- shadcn/ui CLI functional: can add components via `npx shadcn@canary add <component>`
- Design tokens match Dark Pro spec: sidebar #0f1117, content #f8fafc, accent teal
- Dark mode CSS vars configured for admin sidebar

### Non-functional
- Zero breaking changes to existing non-admin pages
- Build must pass after setup

## Architecture
```
globals.css
  └── @theme { admin design tokens }
  └── :root { shadcn CSS vars }
  └── .dark { dark mode vars }
  └── [existing admin CSS — untouched this phase]

components.json (NEW)
  └── shadcn/ui config: aliases, style, tailwind version

tailwind.config.js (NEW — minimal)
  └── content paths only, for CLI compat
```

## Implementation Steps

1. **Install tw-animate-css**
   ```bash
   pnpm add tw-animate-css
   ```

2. **Run shadcn init**
   ```bash
   npx shadcn@canary init
   ```
   - Style: New York
   - Base color: Slate
   - CSS variables: Yes
   - Components alias: `@/components/ui`
   - Utils alias: `@/lib/utils`

3. **Create minimal tailwind.config.js** (if not auto-created)
   ```js
   export default {
     content: ["./src/**/*.{js,ts,jsx,tsx}"],
     theme: { extend: {} },
     plugins: [],
   }
   ```

4. **Add admin design tokens to globals.css** (prepend to existing admin section)
   ```css
   /* Admin Dark Pro Design Tokens */
   :root {
     --admin-sidebar-bg: #0f1117;
     --admin-sidebar-fg: #e2e8f0;
     --admin-sidebar-accent: #1e293b;
     --admin-sidebar-accent-fg: #f8fafc;
     --admin-content-bg: #f8fafc;
     --admin-card-bg: #ffffff;
     --admin-card-border: #e2e8f0;
     --admin-accent: #0d9488;
     --admin-accent-fg: #ffffff;
   }
   ```

5. **Add tw-animate-css import** to globals.css
   ```css
   @import "tw-animate-css";
   ```

6. **Install base shadcn components** needed across all phases
   ```bash
   npx shadcn@canary add button card badge separator tooltip
   ```

7. **Verify build passes**
   ```bash
   pnpm type-check && pnpm build
   ```
