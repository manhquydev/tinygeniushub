# Phase 01 - Foundation & Architecture

## Objective
Set up the stack and technical structure for modular monolith execution.

## Deliverables
- Next.js 16 + TypeScript project scaffold.
- Prisma schema aligned with core product and billing integrity rules.
- Module boundaries under `src/modules`.
- Worker entrypoint for scheduled jobs.

## Acceptance Criteria
- Project boots with `pnpm dev`.
- Prisma schema can be generated and validated.
- Module directories exist for all domains defined in handover.
