POTENTIAL CONCERNS
==================
⚠ Admin access via env var (requires re-deploy to revoke)
⚠ No 2FA/MFA for admin accounts
⚠ Long parent session TTL (30 days)
⚠ No concurrent session limits per admin
⚠ IP resolution relies on RATE_LIMIT_TRUST_PROXY flag
⚠ Admin can disable rate-limit protections via API
⚠ No visible password reset token expiry enforcement
⚠ Session revocation only at next request (not immediate)

UNRESOLVED QUESTIONS

RECOMMENDATIONS
===============
1. Migrate admin access from env var to DB-based for zero-downtime revocation
2. Implement 2FA for admin accounts (TOTP)
3. Add session revocation endpoint
4. Enforce concurrent session limits (1-3 per admin)
5. Reduce parent TTL or add refresh tokens
6. Document rate-limit policy enforcement
7. Create admin audit dashboard
8. Test password reset token expiry
9. Validate IP header configuration in production
10. Plan API key auth for service-to-service
