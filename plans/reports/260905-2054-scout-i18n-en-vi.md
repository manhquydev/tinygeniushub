## Architecture (current)

| Piece | Evidence |
|---|---|
| Locales | `src/i18n/locales.ts`: `defaultLocale="en"`, `supportedLocales=["en","vi"]`, cookie `tgh_locale` |
| Request | `src/i18n/request.ts` reads cookie via `cookies()`, `resolveAppLocale` |
| Plugin | `next.config.ts` `createNextIntlPlugin("./src/i18n/request.ts")` |
| Lib | `next-intl ^4.12.0`, Next 16 App Router |
| Catalogs | `locales/en/translation.json`, `locales/vi/translation.json` |
| Dual API | Server: `translate()` in `src/i18n/translator.ts`. Client: `useTranslations()`. Fallback EN then raw key |
| Provider | `src/app/layout.tsx` `NextIntlClientProvider` + `<html lang={locale}>` |
| Switcher | `src/components/language-switcher.tsx` sets cookie, `router.refresh()` |
| Proxy | `src/proxy.ts` has **no** locale routing |
| Fonts | `Be_Vietnam_Pro` + `Nunito` subsets `latin,vietnamese` |
| Gate | `pnpm check:i18n` bans diacritics in `src/` (catalogs excluded) |

No `[locale]` URL prefix. `/gioi-thieu` etc. redirect to EN paths (`src/app/(main)/gioi-thieu/page.tsx` → `/about`). `/pricing` redirects `/courses`.
